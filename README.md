# retail_sales_analysis
# project overview
This project focuses on performing end-to-end data analysis on a retail dataset using Excel, SQL, and Power BI.
The goal is to extract meaningful business insights related to sales, profit, customers, and regional performance.

## Tools & Technologies
•	Excel (Data Cleaning)
•	MySQL (Data Analysis)
•	Power BI (Dashboard & Visualization)

## 🔍 Key Analysis & Insights
•	Cleaned raw data using Excel (handled missing values and formatting issues)
•	Performed SQL analysis using aggregation functions (SUM, AVG, GROUP BY)
•	Applied CASE WHEN to classify profit and loss orders
•	Used Window Function (RANK) to identify top customers
•	Analyzed regional and country-wise sales performance
•	Identified top customers contributing to revenue
•	Evaluated category and sub-category profitability
•	Studied the impact of discount on profit
•	Built an interactive Power BI dashboard for visualization

## Business Insights
•	High sales regions do not always generate high profit
•	Discounts can negatively impact profitability
•	A small group of customers contributes significantly to revenue
•	Some sub-categories are profitable but have low sales
